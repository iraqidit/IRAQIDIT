# IRAQIDIT — DIT Production Reports (Prototype)

A responsive cinematic front-end for manually maintained DIT reports.

## Preview
Open `index.html` in a modern browser.

## Included
- Project cards and automatic portfolio totals
- Search, add, and edit project reports
- Shooting days, clip counts, data volume, camera, backup status, notes
- Report preview and Print / Save as PDF
- Demo data saved to this browser with localStorage

## Important limitations
This is a front-end prototype. Changes are saved only in the current browser and do not sync to clients or other devices. The editor is not protected by real authentication. Do not enter confidential client information yet.

## Next step for a real live site
Publish these files with GitHub Pages or another static host, then connect a database and secure authentication before using real client data. A public static site alone cannot sync private edits across devices.
